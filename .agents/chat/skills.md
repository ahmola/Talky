# Chat Skills

채팅 어플을 구현한다.

채팅 어플은 클라이언트 - 서버 구조로 이루어진다.

서버는 통신 중계 및 클라이언트 관련 정보 저장을 하는 역할을 하고, 실제 통신은 프론트엔드 앱들끼리 하는 것으로 한다.

실시간 채팅 프로토콜은 WebSocket을, 이외의 기능은 REST API/GraphQL을 사용한다.

서비스 루트 디렉터리에서 docker compose 정의 시, 각 db 컨테이너도 정의한다.

서비스 루트 디렉터리에 각 프로토콜의 구현을 문서로 명세한다.(REST API를 OpenAPI로 문서화하는 것과 유사하게 다른 프로토콜들도 비슷한 방식으로 문서화하며, 이를 기준으로 구현하도록 한다.)

## 클라이언트

1. 웹 앱이며, vue.js를 사용하여 구현한다. SQLite를 DB로 사용하여 필요한 정보들을 저장한다.

2. 클라이언트에서는 로그인과 회원가입, 친구 목록(홈), 채팅창을 구현한다.

3. 로그인은 현재는 보안 프로토콜을 적용하지 않으나, 향후 추가될 가능성을 열어두어 추상화한다.

4. 기본적인 디자인 외형은 KakaoTalk처럼 하되, 테마는 Discord와 비슷한 형식으로 한다.

## 서버

1. 중계 및 데이터 저장의 역할을 하며, Go로 구현한다. PostgreSQL을 DB로 사용한다.

2. WebSocket 통신을 중계하는 기능을 구현한다.

3. REST API/GraphQL로 들어오는 CRUD 요청을 처리하는 기능을 구현한다.

4. 내부 서비스들 간의 통신이 필요한 경우, gRPC로 구현한다.
